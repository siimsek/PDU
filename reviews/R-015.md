## Doğrulama komutları ve çıktıları

Yerel KiCad CLI sürümü `10.0.7` (`kicad-cli.exe version`). Bütün çıktı dosyaları `reports/R-015/` altındadır.

```text
kicad-cli pcb drc --schematic-parity --format json --severity-all -o reports/R-015/pcb-drc-parity.json PDU.kicad_pcb
exit code: 0
violations: 0 (uyarı/hata: 0)
unconnected_items: 402 (tek DRC bulgu türü; izsiz yerleşim için beklenen)
schematic_parity: 0
```

Boş kart ve yerleşimli kart ek kontrolleri, `scripts/pcb_drc.py` çıktısı `reports/R-015/`'e yönlendirilerek alındı:

```text
python -c "import sys,pathlib; sys.path.insert(0,'scripts'); import pcb_drc; pcb_drc.OUT=pathlib.Path('reports/R-015'); raise SystemExit(pcb_drc.main())"
{"empty_errors": {}, "placed_errors_not_allowed": {}, "schematic_parity_issues": 0, "pass": true, "neck_violations": 0}
```

- `drc-empty.json`: ihlal 0, unconnected 0, parity 0.
- `drc-placed.json`: ihlal 0, unconnected 402, parity 0.
- `python scripts/pcb_rules.py --check` → `{"pass": true, "errors": []}`.

Ham CLI çıktısı ve ek denetim JSON'ları: [pcb-drc-parity.json](../reports/R-015/pcb-drc-parity.json), [drc-empty.json](../reports/R-015/drc-empty.json), [drc-placed.json](../reports/R-015/drc-placed.json), [drc-summary.json](../reports/R-015/drc-summary.json), [pcb-rules-check.txt](../reports/R-015/pcb-rules-check.txt).
